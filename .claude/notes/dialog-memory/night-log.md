Решения за владельца:
4. **Раскладка панели памяти на невысоком окне.** Вопрос ui-designer: закреплённый верх

   закреплять только шапку, слово уровня и полосу; пояснение и серые строки прокручиваются
   вместе со списком. Почему: раскладка внутри панели — уровень концепции, ПД (§5.7, §13
   п. 10–12) не меняется, безопасность не затронута. Правка `portal-ui.md` §4.9 —

5. **Минимальная высота окна для приёмки.** Выбор: 1280×720 (ширина из ПД, высота —
   типичный ноутбук). Почему: рекомендация ui-designer; дополняет, а не меняет ПД.
